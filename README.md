# 🚗 CleanDrive

CleanDrive est une application web de lavage automobile qui permet de consulter les prestations disponibles, générer des devis en PDF et gérer les services en ligne.

---

## 🚀 Fonctionnalités

- Consultation des prestations et services
- Génération automatique de devis PDF
- Interface en MVC avec base de données MySQL
- Gestion des clients et authentification
